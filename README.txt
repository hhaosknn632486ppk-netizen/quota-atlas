Quota Atlas · 额度指南 0.8.2
Windows 10 / 11 x64 公开测试候选版

安装与启动
将 ZIP 完整解压到普通本地文件夹，保留 app、runtime 和所有脚本。
双击 install.cmd，校验文件后安装到当前用户目录并创建开始菜单入口。
以后从开始菜单打开；默认先显示紧凑悬浮窗。
便携使用可直接双击解压目录的 start.cmd。
此版本尚未签名，请核对可信渠道的 ZIP SHA-256；文件摘要不等于软件签名。

悬浮窗
拖动顶部移动；图钉切换置顶；箭头展开或收起；点击详情入口打开完整面板。
× 隐藏到托盘，点击托盘恢复。完全退出使用托盘菜单“退出”。
设置中可以选择主要显示的账户。百分比、积分和货币余额各自保留单位。

连接账户
Codex 与 WorkBuddy 可读取本机已登录客户端的受支持额度，已有真实账号验证。
Claude 提供本机检测和工具内网页登录，官方订阅账号的真实验证尚未完成。
DeepSeek、Gemini、Grok 的网页 / 订阅与 API 独立显示，不共用余额。
三个 API 接入已有模拟响应测试，尚未完成真实账号验证。
网页额度提取为实验功能；其他账户可手动记录。未知额度不会估算成已知数值。
具体要求和限制见 CONNECTIONS.txt、SUPPORT.txt。

额度动态与提醒
活动区分重置、赠送、重置券、需要领取及套餐限制，卡片内给出已知时间和操作。
同一活动的后续更新合并显示；不能确认属于同一活动时保留独立记录。
首次启动历史消息静默。未知适用条件明确标记；可信直达消息可按偏好轻提醒。
个人余额增加只说明观察到了变化，不据此断言某个活动已到账。
设置中可选择关注平台、待确认消息与免打扰时段。
应用运行且网络可用时轮询来源；退出或休眠期间不保证即时发现。
部分官方来源在当前网络无法访问，设置页展示实际连接情况。

检查通知
安装后进入详细面板 → 设置 → 发送测试通知。
状态区分 Windows 已报告显示、失败、未确认或被本工具设置抑制。
Windows 勿扰、系统通知开关等会影响横幅；“已报告显示”不代表你已经看见。
测试不会替你更改 Windows 通知偏好，也不保证每条未来消息可见。

语言
设置 → 语言，支持简体中文、English、日本語、한국어和跟随系统。
原始公告保留原文。

更新与卸载
下载新版本并完整解压，双击其中的 update.cmd；独立账户资料和设置保留。
目前没有在线自动更新。升级后旧版本目录保留。
从已安装版本目录运行 uninstall.cmd，移除本工具的已验证版本和相应入口。
卸载保留账户资料；如需彻底清除，可退出程序后自行删除该数据目录。

数据与隐私
便携数据位于解压目录的 .local；安装数据默认位于 LocalAppData/QuotaAtlas/data。
首次安装可迁移本工具已有便携资料；已有安装资料不会被更新覆盖。
API 密钥可仅本次运行使用，或按选项用 Windows 加密保存。
网页登录使用独立本机会话。发布包不含开发者账号、密钥、会话、日志及测试记录。
开机启动默认关闭。网络访问和数据保存详见 PRIVACY.txt。

本版本适合小范围测试；真实接入覆盖、网络来源和横幅仍需更多环境验证。
反馈时请提供版本、Windows 版本、操作步骤及不含密钥的错误说明。
不要发送密钥、Cookie、账号令牌或整个用户数据目录。

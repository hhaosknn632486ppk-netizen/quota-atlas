# Quota Atlas · 额度指南

[English](README.md) · Windows 10/11 x64 · 早期 Beta · MIT

统一查看 AI 服务额度，追踪重置与赠送活动，说明适用条件、时间和可采取的操作。
支持紧凑悬浮窗、完整面板、关注平台、免打扰及四种界面语言。
百分比、积分、货币和订阅/API 账户分别显示，未知数据保持未知。

## 下载与使用

如果维护者已经发布版本，从本仓库 **Releases** 选择 Windows x64 **预发布版**。
GitHub 自动生成的源码 ZIP 不包含桌面运行时，不能直接当安装包使用。

1. 下载 `QuotaAtlas-<版本>-windows-x64.zip` 和对应 `.sha256`。
2. 与可信来源的摘要核对后完整解压。
3. 运行 `install.cmd`，以后从开始菜单打开。
4. 在设置中选择语言、主要账户、关注平台和提醒偏好。
5. 用“发送测试通知”检查本机；系统回执不等于已经看到横幅。

目前未签名，文件摘要不替代软件签名。安装资料与程序分开保存。
更新运行新版本的 `update.cmd`；卸载运行已安装副本中的 `uninstall.cmd`，默认保留账户资料。
没有在线自动更新。

## 从源码运行

使用 Windows x64、Node.js 24 LTS、Git、npm。锁文件由 npm 10.9.4 生成。

```sh
npm ci
npm run setup
npm run demo
```

首次 setup 从 Electron 官方 GitHub 下载固定版本，按 `config/runtime.json` 校验 SHA-256，
解压到 `.cache`，需要网络。演示使用独立资料，不后台读取运营商、不发系统通知。
实际使用运行 `npm start`；该模式可检测已有 Codex 登录并读取已启用的连接。
不要分享 `.local` 和 `.cache`。

```sh
npm run check
npm test
npm run test:desktop
npm run test:installer
npm run build
npm run verify:package
npm run test:package
npm run release:source
```

检查和单元测试也可在 Linux 运行，其余桌面/安装/打包命令需要 Windows x64。
安装安全测试只操作隔离目录的假程序文件，不运行它们，不创建开始菜单或自启动项。
产物写入 `dist`，不静默覆盖已有发布包。

## 提醒原则与当前限制

区分自动重置、赠金、重置券和需要领取的活动，将已知时间、套餐、渠道及操作保留在卡片中。
能确认的同一活动合并更新；历史消息首次静默；未知适用性明确展示。
观察到账户余额增加，不据此推断是哪次活动造成。

最近的开发网络检查中，OpenAI、Gemini、xAI 的部分官方公告入口未能读通。
访问失败不等于没有活动。应用退出、休眠及上游延迟会影响发现时机；规则解析可能遗漏特殊措辞。
不预测未公开的重置，不保证覆盖全部消息或适用于个人账户。

独立电脑接入、更多真实账号、物理断网、长时间休眠和长期稳定性仍需验证。
CI 使用模拟数据，不代表这些真实场景已通过。

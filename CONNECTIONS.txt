Quota Atlas 0.8.2 · 接入说明

验证状态
Codex、WorkBuddy：开发机真实账号读取已验证，其他电脑和客户端版本仍需测试。
Claude 官方订阅、DeepSeek / Gemini / Grok API：已有模拟数据测试，真实账号授权未验证。
网页用量观测为实验功能。未知数据保持未知，不用限额上限冒充剩余额度。

Codex
本机需要已有官方客户端及有效登录，工具通过只读额度方法读取。
自动额度每分钟更新，不把 ChatGPT 与 Codex 的额度混为同一个账户。

WorkBuddy
本机登录并保持兼容的新版 Windows WorkBuddy 运行。
在“账户与额度”点击“连接本机账号”，无需复制令牌。
每 5 分钟读取受支持的 Credits 汇总；关闭客户端后保留历史值并显示错误/缓存状态。
额度包是总额的组成部分，不能与总额再次相加。
接口未返回各赠送包到期时间时，不显示猜测的到期时间。

Claude（实验性）
可检测本机官方 Claude Code 的有效登录，也可使用工具内的独立网页登录。
不修改或续写官方客户端共享登录文件；登录失效时请在官方客户端重新登录。
自定义第三方 Claude 服务与 Anthropic 官方订阅区分，暂不能自动读取任意第三方额度。
网页与本机登录是同一订阅行的两种读取方式，切换时停止另一方式。
多组织、验证页面、客户端内部接口变化可能导致无法读取；当前未完成真实官方订阅验证。

DeepSeek API（实验性）
在 API 入口填写自己的 DeepSeek API Key，读取总余额及可用赠金/充值余额。
总余额已包含分项，不再次相加。没有赠金期限时，不生成期限。
官方文档：https://api-docs.deepseek.com/api/get-user-balance/
控制台：https://platform.deepseek.com/

Grok API（实验性）
当前适配要求 xAI Management Key 和团队 ID；普通推理 API Key 不等同于账单读取权限。
只读预付 API 余额，不操作充值、消费限制或账单。
预付余额不代表网页订阅额度或后付费可消费总额。
官方文档：https://docs.x.ai/developers/management-api-guide
控制台：https://console.x.ai/

Gemini API（实验性）
当前适配需要 Google Cloud 项目 ID/编号与有权限的 OAuth access token。
普通 AI Studio API Key 不等同于完整项目用量的读取权限。
所需读取权限涉及 serviceusage.quotas.get 和 monitoring.timeSeries.list。
令牌会过期；建议仅本次运行使用，不要发送到聊天或 Issue。
只有近期用量与每日窗口能唯一匹配时才计算剩余量；分钟限额只展示上限。
没有监控数据不代表零用量或满额。API 每日窗口与网页订阅独立，时间按本机时区展示。
官方文档：https://ai.google.dev/gemini-api/docs/rate-limits
控制台：https://aistudio.google.com/usage

网页/订阅（实验性页面观测）
使用独立官方窗口登录并进入用量页面，工具只读取明确标注方向的用量字段。
页面无明确个人额度数据、结构变化或语言不支持时，显示未知并可改为手动记录。
不提取聊天内容作为额度，不复用系统浏览器 Cookie，不自动刷新网页。
保持页面打开时观测；关闭窗口后保留历史值，重启不会自动打开普通观测窗口。
Claude 的专用网页登录连接行为以界面说明为准。

公开消息
无需密钥的官方公告、规则页和聚合源按内置间隔检查，退出或休眠期间不会检查。
可选 X 账号直读需要自己的 X 官方 API Bearer Token 和权限，可能收费，默认关闭。
未提供真实 X 权限验证，模拟测试不保证真实账号可用。
原文身份、套餐、渠道或适用条件未知时保持待确认；可信直读消息可按偏好轻提醒。
规则页变动不自动等于赠金；账户余额增加不自动等于某次活动到账。
部分官方入口在开发网络不可达。设置中展示来源的实际健康情况。

凭据和资料
按用户选择，仅本次运行保存，或使用 Windows DPAPI 加密保存；没有明文后备方案。
“断开 API”删除对应密钥和 API 记录，不影响同平台网页记录。
便携资料位于 .local；安装模式使用独立用户数据目录。
凭据文件、浏览器会话、缓存、账号快照都属于私密资料，不要上传整个目录。
反馈只提供版本、步骤、公开链接和已脱敏的错误类别。
权限、接口及计费可能变化，请以服务商当前控制台和文档为准。
